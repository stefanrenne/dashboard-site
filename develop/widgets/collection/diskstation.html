Synology DiskStation

type: diskstation · version 0.5.0 · widget API 2 · Widget collection develop · source

Uptime, the free space on a volume (marked below 10%), and the CPU and memory in use of a Synology NAS, as homepage’s diskstation widget. volume picks a volume when there are several: volume_1, volume_2, … (default the first one DSM lists).

These figures are only open to members of the Administrators group. Limit such a user: in DSM 7, Control Panel > User & Group > Create, check Administrators under User Groups, No Access on all shared folders under Permissions, and under Applications Deny all but DSM. Two-step verification cannot be on for this user. If logins get blocked while you set it up, uncheck Control Panel > Security > Protection > Enable auto block for a moment.

Learn more about Synology DSM.

Display fields

uptime, volumeAvailable, resources.cpu, resources.mem

Pick them with fields: in the entry.

Configuration options

Option Type Required Default Description
url url yes   E.g. http://nas.lan:5000
username string yes   An administrator without access to files (see the page)
password string yes   Secret: stays on the server.
volume string     Volume_1, volume_2, …; default the first volume
insecure boolean   false Accept a self-signed certificate (https on port 5001)

Every widget also takes refresh (or refreshInterval in ms), fields and hideErrors; see Services.

Filter attributes

Public values a service’s filter: can read, as widget.<attribute>; see Filters.

Attribute Type Description
attention boolean True while the card marks something as needing attention
uptimeHours number Hours since the NAS started
volumeFree number Free space on the volume, in GB
volumeFreePercent number Free space on the volume, in % of its size

Example 

# services.yaml
- Storage:
    - DiskStation:
        href: http://nas.lan:5000
        icon: synology
        widget:
          type: diskstation
          fields: [uptime, volumeAvailable, resources.cpu, resources.mem]   # the display fields; leave out for the defaults
          url: http://nas.lan:5000
          username: remote_stats
          password: "{{DASHBOARD_VAR_SYNOLOGY_PASSWORD}}"
          volume: volume_1
