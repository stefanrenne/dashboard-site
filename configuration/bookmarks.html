Bookmarks

The settings page edits this file under Bookmarks as a form; “Advanced edit” opens it as text under Advanced.

bookmarks.yaml holds groups of plain links, shown below the service groups (or between them, with layout in settings.yaml).

- Developer:
    - GitHub:
        - abbr: GH
          href: https://github.com
          icon: github.svg

The homepage form (a one-item list) and a plain map (GitHub: { href: ... }) both work.

icon takes the same forms as a service icon; see Images. abbr is shown when there is no icon. With bookmarksStyle: icons in settings.yaml, or iconsOnly: true on a group in layout, a group shows only its icons.
