Feed

type: feed · version 0.3.0 · widget API 2 · Widget collection develop · source

The latest items of an RSS 2.0 or Atom feed, as homepage’s feed widget: layout: list (the default) shows a line per item with its age and a small thumbnail, layout: grid image tiles that fill the card’s width. maxItems sets how many (default 5). Items open in a new tab.

Images come from the item’s media:thumbnail or media:content, an image enclosure, or else the first image in its content; some feeds have none. Your browser loads them from the feed’s host, at the size the feed links; set images: false for feeds whose images are slow. The dashboard fetches the feed itself, at most every 10 minutes.

Learn more about RSS.

Display fields

No blocks: the items are drawn by the widget.

Configuration options

Option Type Required Default Description
url url yes   The feed, e.g. https://example.com/rss.xml
maxItems number   5  
layout string   list List, or grid for image tiles
images boolean   true False hides the images

Every widget also takes refresh (or refreshInterval in ms), fields and hideErrors; see Services.

Filter attributes

Public values a service’s filter: can read, as widget.<attribute>; see Filters.

Attribute Type Description
items number Items in the feed
recent number Items published in the last 24 hours

Example 

# services.yaml
- News:
    - Homelab news:
        widget:
          type: feed
          url: https://news.example.com/rss.xml
          maxItems: 8
          layout: grid
