Widgets

A widget puts live data on the dashboard. There are two kinds, as in homepage:

  • Service widgets go on a service’s card in services.yaml, under widget: (or widgets: for several). They show the numbers of that service: the queue of Radarr, the blocked queries of Pi-hole, the VMs of Proxmox.

    # services.yaml
- Media:
    - Radarr:
        href: http://radarr.lan
        icon: radarr.svg
        widget:
          type: radarr
          url: http://radarr.lan:7878
          key: "{{DASHBOARD_VAR_RADARR_KEY}}"

  • Header widgets go in the page’s header, in widgets.yaml: the date and time, system resources, search, the weather.

    # widgets.yaml
- openmeteo:
    label: Amsterdam
    latitude: 52.37
    longitude: 4.89

Every widget below comes from the widgets collection, which is always installed. Missing one? Any widget package can be added under plugins:: the Catalogue lists packages by others, and Extend shows how to write your own.

Header widgets

Widget type What it shows
Date and time datetime The current date and time, formatted for the dashboard language.
Greeting greeting A line of text in the header, as in homepage’s greeting widget.
Kubernetes kubernetes CPU and memory of a Kubernetes cluster (the one the dashboard runs in, or kubernetes.yaml’s kubeconfig), in total and per node (homepage’s kubernetes widget).
Logo logo A logo in the header: the dashboard’s own mark, or an icon of your choice, as in homepage.
Open-Meteo openmeteo The current weather from Open-Meteo, no account needed (homepage’s recommended weather widget).
OpenWeatherMap openweathermap The current weather from OpenWeatherMap, with your API key or a shared provider (homepage’s openweathermap widget).
System resources resources CPU, memory, disk, CPU temperature, uptime and network of the machine (or container) the dashboard runs on, as meters like homepage.
Search search Filters the dashboard’s services as you type; Enter opens the only match, or searches the web.
Stocks stocks The price and day change of up to eight stocks, from Finnhub (homepage’s stocks widget).
