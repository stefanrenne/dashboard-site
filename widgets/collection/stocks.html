Stocks

type: stocks · version 1.3.1 · widget API 2 · Widget collection v0.17.0 · source

The current price and the day’s change of up to eight stocks, from Finnhub. Sign up for a free API key at Finnhub, then put it once in settings.yaml under providers and use provider: finnhub (as in homepage), or set apiKey. The key stays on the server. Up and down are shown with ▲ and ▼; color: false leaves out the green and red. cache keeps the prices for that many minutes (Finnhub’s free tier allows 60 calls a minute, one per symbol).

Learn more about Finnhub.

Display fields

One block per symbol in the watchlist, named after it (AAPL)

Pick them with fields: in the entry.

Configuration options

Option Type Required Default Description
url url   https://finnhub.io The Finnhub API
watchlist list yes   Ticker symbols, at most 8, e.g. [AAPL, MSFT, BRK.A]
apiKey string yes   Secret: stays on the server. Or provider: finnhub (settings.yaml providers)
color boolean   true Green up, red down (the arrows show it either way)
cache number   1 Minutes between calls to Finnhub

Every widget also takes refresh (or refreshInterval in ms), fields and hideErrors; see Services.

Filter attributes

Public values a service’s filter: can read, as widget.<attribute>; see Filters.

Attribute Type Description
AAPL number Price of a symbol in the watchlist, named after it (here AAPL), in its currency

Example 

# settings.yaml
providers:
  finnhub: "{{DASHBOARD_VAR_FINNHUB_KEY}}"

# widgets.yaml
- stocks:
    fields: [AAPL]   # the display fields; leave out for the defaults
    provider: finnhub
    color: true
    cache: 1
    watchlist: [AAPL, MSFT, NVDA, BRK.A]
